# Aset SIOMAY

- `icon.svg` adalah sumber ikon SIOMAY yang dapat diedit.
- `icon.png` adalah raster 1024 × 1024 untuk metadata aplikasi.
- `icon.ico` adalah ikon Windows multiresolusi untuk aplikasi dan installer.

Jika ikon diubah, buat ulang `icon.png` dan `icon.ico` dari sumber SVG sebelum membuat rilis Windows.
