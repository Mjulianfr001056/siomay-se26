# 🥟 SIOMAY v2026.1.9

Pembaruan ini menghadirkan dokumen **Surat Pernyataan Tidak Ditemukan (SPTD)** dan dukungan **folder publik Google Drive** untuk menyisipkan banyak gambar bukti secara otomatis.

## ✨ Yang Baru

- 📄 Menambahkan pilihan dokumen SPTD lengkap dengan template Word dan format input Excel bawaan.
- 🧮 Jumlah responden SPTD dihitung otomatis dari jumlah keluarga ditambah jumlah usaha pada setiap baris data mitra.
- 🖼️ Kolom bukti dukung BAPP Termin 1, BAPP Termin 2, dan BAST kini dapat diisi dengan satu tautan folder publik Google Drive.
- 🏷️ Placeholder gambar kustom juga dapat menerima tautan folder publik Google Drive.
- 🔢 Seluruh gambar yang langsung berada di dalam folder disisipkan menurut urutan alami nama file; subfolder dan file non-gambar dilewati.
- 🔐 Daftar gambar diproses melalui Cloudflare Worker SIOMAY sehingga Google API key tidak pernah disimpan atau dikirim ke aplikasi desktop.
- 🛡️ Placeholder SPTD yang terpisah pada beberapa *run* Word kini dapat diganti tanpa merusak format teks di sekitarnya.
- ✅ Validasi dan pengujian ditambahkan untuk input SPTD, generasi dokumen, paginasi folder, filter gambar, urutan file, respons layanan, dan integrasi generator.

Terima kasih telah menggunakan **SIOMAY**! 🚀

## 📦 Unduhan

Unduh **`SIOMAY-v2026.1.9-windows.zip`**, ekstrak seluruh isi arsip ke folder baru, lalu jalankan **`SIOMAY.exe`**.

> Jangan menjalankan aplikasi langsung dari dalam arsip ZIP dan pastikan folder pendamping, termasuk `LibreOffice`, tetap berada bersama `SIOMAY.exe`.
